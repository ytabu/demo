\ About this site /

Claude Code とは？

Anthropicが提供するAIペアプログラマー。
ターミナルから自然言語で指示するだけで、コードの生成・修正・コミット・PRまで担当します。

Claude Code はエディタに統合されたAIアシスタントではなく、ターミナル上で動くエージェントです。プロジェクト全体のファイルを読み書きしながら、複数のファイルにまたがる変更も一気に実行できます。

このサイト自体も Claude Code を通じてデザイン・コーディング・Gitコミット・GitHub PRの作成をすべてAIに指示しながら構築しました。

開発ツールとしてだけでなく、アイデアを素早く形にする相棒として活用できます。

Setup Guide

設定方法

Windows に Claude Code をインストールして使い始めるまでの手順です。

1

Anthropic アカウントを作成する

claude.ai にアクセスしてアカウントを作成します。Claude Code を使うには Pro プラン以上（月額 $20〜）へのサブスクリプションが必要です。

または Anthropic Console からAPIキーを発行してAPIプランで利用することもできます。

2

Node.js をインストールする

Claude Code の実行には Node.js（v18以上）が必要です。Windows 10/11 に標準搭載の winget を使えばコマンド一発でインストールできます。スタートメニューで「PowerShell」と検索して起動し、以下を実行してください：

winget install OpenJS.NodeJS

インストール後、PowerShell を一度閉じて再起動し、バージョン確認：

node -v
npm -v
3

Claude Code をインストールする

npm でグローバルインストールします。PowerShell（管理者権限）で実行してください：

npm install -g @anthropic-ai/claude-code

インストール後、バージョン確認：

claude --version
4

認証する

プロジェクトフォルダに移動して claude を初回起動すると、ブラウザが開いて Anthropic アカウントでのログイン画面が表示されます。

cd あなたのプロジェクトフォルダ
claude

ブラウザで認証を完了すると、ターミナルの Claude Code セッションが開始します。

5

使い始める

セッションが開始したら、日本語で自由に指示できます。最初は何もない空のフォルダでOKです。例えば：

Pythonで簡単なWebページを作りたい。必要なファイルを作成して

Claude Code がファイル構成を考えてコードを生成してくれます。慣れてきたら「デザインを緑系にして」「お問い合わせページを追加して」のように変更を重ねていけます。

Bonus

おまけ：このページの自動公開の仕組み

このページは Claude Code・GitHub・Railway の3つを連携させることで、
コードを書いてから公開までほぼ自動で完結しています。

🤖

Claude Code

コードを書く・変更する

ターミナル上で動くAIエージェント。「デザインを緑にして」「設定方法を追加して」など自然言語で指示すると、HTML・CSS・Pythonを横断してコードを修正し、Gitコミット・PRの作成まで実行します。

↓
🐙

GitHub

コードを管理・マージする

ソースコードのホスティングサービス。Claude Code が作成したPR（プルリクエスト）をブラウザ上で確認してマージするだけで、最新コードが master ブランチに反映されます。

↓
🚂

Railway

自動でビルド・公開する

GitHubリポジトリと連携したホスティングサービス。master ブランチへのマージを検知すると自動でビルドが走り、数分以内に本番環境へ反映されます。サーバー管理は不要です。

つまり「AIに指示 → PRをマージ」の2ステップだけで、このページは更新・公開されています。
